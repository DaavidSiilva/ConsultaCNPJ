# Consulta CNPJ
![Exemplo](https://github.com/user-attachments/assets/77173f94-7b27-404f-b90a-e032ddc62284)

Esta página fornece uma interface simples e eficiente para consultar dados cadastrais de empresas (CNPJ) diretamente do seu navegador, sem necessidade de instalação de softwares complexos ou servidores.

## Como Usar

Para utilizar a ferramenta, siga os passos abaixo:

1.  **Baixe o arquivo**: Faça o download do arquivo `ConsultaCNPJ.html` presente neste repositório.
2.  **Abra no Navegador**: Dê um clique duplo no arquivo baixado ou arraste-o para o seu navegador de preferência (Chrome, Edge, Firefox, etc.).
3.  **Realize a Consulta**: Digite o CNPJ que deseja pesquisar no campo indicado e clique no botão **Consultar**.

## Informações Importantes

*   **Fonte de Dados**: A consulta é realizada utilizando uma [API Pública](https://www.cnpj.ws/).
*   **Limitações**: A API possui um limite de **3 consultas por minuto**. Caso receba um aviso de limite excedido, por favor, aguarde alguns instantes antes de realizar uma nova busca.

## Tecnologias

*   HTML5
*   JavaScript (Vanilla)
*   Tailwind CSS (via CDN)
